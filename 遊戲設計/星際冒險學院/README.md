# 星際冒險學院

供國小學生使用的冒險升級主題遊戲專案。此資料夾保留可直接開啟的單機版遊戲、原始封存檔與遊戲設計簡報。

## 快速使用

1. 以瀏覽器開啟 `星際冒險學院 單機版.html`。
2. 第一次開啟時請稍候，檔案會先載入內嵌的遊戲資源。
3. 在電腦、平板與手機上實際操作主要流程；發布前請再次確認文字、音效與觸控操作。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `星際冒險學院 單機版.html` | 可離線開啟的遊戲成品，內含執行所需資源。 |
| `國小學生冒險升級遊戲設計.zip` | 遊戲來源封存檔，供後續還原或再編輯使用。 |
| `冒險學院遊戲設計.pptx` | 遊戲機制與教學設計簡報。 |

## 維護原則

- 發布或改版前，先保留原始 `zip` 檔，再替換單機版 `html`。
- 不直接手動修改已打包的單機版 `html`；應以來源檔重新產生，降低內嵌資源損毀風險。
- 新增暫存檔、瀏覽器測試輸出或本機設定時，請放入已忽略的資料夾。
