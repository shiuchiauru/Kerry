# 教學工具總倉庫

這個專案用來集中管理教學用的小工具、教材產出流程、課堂輔助頁面與可重複使用的教案資源。

## 資料夾規劃

- `tools/`：互動式教學工具、小程式、網頁工具。
- `materials/`：教材、學習單、講義與課堂素材。
- `templates/`：可重複套用的文件、簡報、活動設計模板。
- `docs/`：專案說明、工作流程與使用紀錄。

## 工作原則

- 優先製作可直接上課使用的成果。
- 網頁與互動工具需支援響應式版面。
- 檔案命名盡量清楚，包含主題、年級或用途。
- 重要變更請透過 Git 留下紀錄。

## 快速開始

1. 將新工具放入 `tools/`。
2. 將教材與模板分別放入 `materials/` 與 `templates/`。
3. 若新增工具需要特殊使用方式，請在 `docs/` 補充說明。
